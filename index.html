01 · Explorar

Seleccionar y aislar

Caras: superficies planas conectadas de la malla. Aristas: clic cerca de una línea; muestra longitud y extremos. Ctrl añade, Shift quita.

Si se selecciona todo junto, prueba Piezas conectadas. Si la geometría está unida, usa Superficies planas para aislar caras. No identifica muros o losas automáticamente.

Clic para seleccionar · Ctrl + clic para añadir · Shift + clic para quitar · Alt + clic para recorrer piezas superpuestas, también en planta. Arrastra: izquierda → derecha contiene; derecha → izquierda cruza. Ctrl añade y Shift quita también por rectángulo.

Ningún elemento seleccionado.

Arrastra para girar · botón derecho para desplazar · rueda para acercar. Selecciona con un clic breve.

Editar selección y grupos

Con varias selecciones, el nombre se numera. Los grupos guardan la selección; no unen geometría ni cambian el SKP. Guarda la sesión para conservar nombres, colores y grupos.

Capas y propiedades

Aislar por propiedades
El filtro por color usa el color del editor. Las capas controlan sus miembros en el modo de separación en que fueron asignados. Propiedades del visor, guardadas en la sesión; no modifican el SKP.
02 · Medir




Cota: elige el eje y marca dos puntos. La separación positiva o negativa cambia el lado; puedes editarla en cada cota.







03 · Referencia vertical


Cota exportada = Z del SKP − referencia. Se conserva X/Y del modelo; no se asignan coordenadas geográficas.
